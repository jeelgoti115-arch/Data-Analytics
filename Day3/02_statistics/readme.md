### Statistics in Data Science
- The science of collecting, analyzing, interpreting, and presenting data
- Foundational backbone that transforms raw data into reliable insights, powers machine learning algorithms, and validates predictive models

### Types of Statistics
- **Descriptive Statistics:** Summarizes and organizes the main features of a dataset using metrics like central tendency (mean, median, mode) and dispersion (variance, standard deviation, range) to make large amounts of data understandable.
- **Inferential Statistics:** Uses a smaller sample of data to make predictions, test assumptions, or draw conclusions about a larger population

### Key Statistical Concepts
- **Probability & Distributions:** Models uncertainty and predicts the likelihood of future events 
- **Hypothesis Testing:** Evaluates assumptions or compares groups using tests like t-tests, ANOVA, and chi-squared tests.
- **Correlation & Regression:** Measures relationships between variables and forecasts numerical outcomes.
- **Bayesian Statistics:** Incorporates prior domain knowledge to update the probability of a hypothesis as new data arrives.
